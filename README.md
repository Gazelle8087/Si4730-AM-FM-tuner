# Si4730-M02 AM/FM tuner

共立エレショップで限定特価にて販売されている  
Si4730-D60 搭載のチューナーモジュールを  
マイコンを使って動作させてみました  

同じチューナーチップを使っていると推定される  
私自身所有のONKYOのレシーバー TX-8050をベンチマークとし  
同等の感度・音質目指し、UIを自分の好みに仕上げ  
普段使いできるチューナーに仕立てました  

共立エレショップで扱われている商品に関しては以下リンク先ご参照ください  
https://eleshop.jp/shop/g/gQ1D411/

## プリント基板

JLCPCBに発注した設計データですが、Rev1.00では以下不具合があります  

- 位置決めピン穴開け忘れのため、超小型バックライト付LCDが搭載できません  
- チューナーモジュールのシールド足のピッチとランドがわずかにずれています

- インダクタの10μH品の体格が大きいため、ランドのピッチと合いません  
  47μH品は合ってます  
- 未使用部品C21のランドが残っています

## 主な仕様

受信範囲  
AM 522kHz  ～ 1710kHz  
FM 76.0MHz ～ 95.0MHz  

プリセットチャンネル数 144（12バンク×12ch)  
バンク、ch番号は 1～9,A,B,C で表示

ファインチューニングモードにて  
AM 1kHz FM 10kHz にて微調整可能  

チャンネルフィルタ変更可能  
AM (1.0kHz 1.8kHz 2.0kHz 2.5kHz 3.0kHz 4.0kHz 6.0kHz)  
FM (40kHz 60kHz 84kHz 110kHz 自動選択)  

RCA定格出力・出力インピーダンス 200mV/1.2kΩ（回路から推定）  
アンプにつないだ場合、音量最大(63)で単品チューナーと同程度の音量です  

消費電力 5V 50mA（試作機実測値）  

RCAジャックと3.5mmジャックは並列接続  
（3.5mmジャックに刺してもRCA出力はOFFになりません）  

USBから電源を取るパワードスピーカーへの給電のための  
USB-Aコネクタ搭載可能  

## TX-8050との比較

以下あくまで主観評価です  

【受信感度】  
AM・FM共に感度に関しては同等です  

【音質】  
アンプはTX-8050を使い、内蔵チューナーと本機を切替ながら比較しました  

FMに関しては同等でした  

AMに関しては、近隣の局の場合チャンネルフィルタを6kHzに設定すれば  
本機の方がより高音が伸び、クリア聞こえます  
聞き比べてみますと、TX-8050はチャンネルフィルタを  
4kHzに固定しているようで、本機で4kHz設定した場合と同程度でした  

【選択度】  
チューナーチップの性能は同じですが  
チャンネルフィルタ切替と周波数微調整機能にて  
TX-8050では聞き取れない局が聞こえる場面もありました  

【リモコン操作性】  

TX-8050はプリセットメモリ1～40chで、ダイレクト呼び出しの際  
5～9CHは一発で、それ以外は2桁指定となっています  

本機ではバンク方式とし、バンク内12chは1ボタン選局できるようにしました  
バンク違いの局をコールするには  
[メニュー] [バンク番号] [ch番号]と3アクション必要ですが  
十字キーの左右でプリセット±する場合は  
バンクを跨いでchを切り替えます  

【ワイドFM対応】  
本機ではワイドFMに対応しました。  
（ONKYOレシーバーは後継機種TX-8150でワイドFM対応になりました）  

## チューナーモジュール Si4730-M02 について

![内部](https://github.com/Gazelle8087/Si4730-AM-FM-tuner/blob/main/Si4730-M02_inside.JPG)  

この品はオーディオメーカーのAVアンプのチューナーモジュールらしく  
しっかりとしたシールドに納められ、FM外部アンテナ接続用のF型接栓  
AMループアンテナ接続用端子、Si4730音声出力をRCAレベルに増幅する  
バッファアンプまで内蔵しています  

一方で、Si4730制御が、非SPIの双方向3線シリアルに設定されていて  
有名なライブラリPU2CLRが使えません  
Si4730とのデータ授受をGPIOを使ったビットバングで制御する必要があります  
内部の配線を見ると、3線シリアルにするための結線がチップの下で  
実施されているようでそこを改造するのは難しそうでした

また、シールドを開けて中を観察すると、AV機器らしくノイズなどに配慮した  
回路・配置・構造になっています

## ⚠️ 短波（SW）拡張に関して
- 本モジュール（Si4730-M02）に搭載されているSi4730-D60は  
  ファームウェア（AMコンポーネント）のバリデーターが 1,710 kHz（北米拡張MW上限）  
  で厳格にハードコードされており、1711kHz以上の値を送ると即座にステータス `0xC1` (ERR=1)  
  を返してコマンドを拒否します  
- ネット上で散見される `0x3102` や `0x3103` などのプロパティを用いた「SW解放の裏技」は  
  ファームウエアの仕様変更で完全に塞がれている模様です  
- もし「起動時のPOWER_UPパッチ上書き」などでここを突破できた方がいらっしゃいましたら  
  ぜひ教えてください！  
- ただし、その場合でも本モジュールのAMアンテナ入力回路はMW(中波)に最適化されているため  
  別途その部分の改造が必要です
