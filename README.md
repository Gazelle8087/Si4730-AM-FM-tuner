# Si4730-M02 AM/FM tuner

共立エレショップで限定特価にて販売されている  
Si4730-D60 搭載のチューナーモジュールを  
マイコンを使って動作させてみました。  

私自身が所有する ONKYOのレシーバー TX-8050をベンチマークとし、  
同等の感度・音質を、それ以上の機能・操作性を目指しました。  

共立エレショップで扱われている商品に関しては以下リンク先ご参照ください。  
https://eleshop.jp/shop/g/gQ1D411/

## ビルド環境

IDE: Arduino IDE 2.3.10  
ターゲットマイコン：Atmega328P  

MiniCore ブートローダを使用し  
8MHz 内蔵RC発振 BOD1.8Vに設定ください。  
シリアルコンソールは 9600bpsを使っています。  

## スケッチについて

リポジトリ内 SI4730_IR.ino をご参照ください。  
シングルソースです。

## 主な仕様

受信範囲  
AM 522kHz  ～ 1602kHz  
FM 76.0MHz ～ 95.0MHz  

プリセットチャンネル数 144（12バンク×12ch)  
バンク、ch番号は 1～9,A,B,C で表示

ファインチューニングモードにて  
AM 1kHz FM 10kHz にて微調整可能  

チャンネルフィルタ変更可能  
AM (1.0kHz 1.8kHz 2.0kHz 2.5kHz 3.0kHz 4.0kHz 6.0kHz)  
FM (40kHz 60kHz 84kHz 自動選択)  

RCA定格出力・インピーダンス 200mV/1.2kΩ（回路から推定）  
アンプにつないだ場合、音量最大(63)で単品チューナーと同程度の音量です  

消費電力 5V 50mA（試作機実測値）  

RCAジャックと3.5mmジャックは並列接続  
（3.5mmジャックに刺してもRCA出力はOFFになりません）  

USBから電源を取るパワードスピーカーへの給電のための  
USB-Aコネクタ装備済  

## TX-8050との比較

以下、あくまで主観評価です。  
追って、受信音をキャプチャした結果や解析した結果も  
追加していきます。  

【受信感度】 
TX-8050に使われているチューナーチップは Si4730と推定され  
AM・FM共に感度に関しては同等です。  

【音質】  
アンプはTX-8050を使い、内蔵チューナーと本機を  
切替ながら比較しました。  

FMに関しては同等でした。  

AMに関しては、近隣の局の場合チャンネルフィルタを6kHzに設定すれば  
本機の方がより高音が伸び、クリア聞こえます。  
聞き比べてみますと、TX-8050はチャンエルフィルタを  
4kHzに固定しているようで、本機で4kHz設定した場合と同程度でした。  

【選択度】  
チューナーチップの性能は同じですが、  
チャンネルフィルタ切替と周波数微調整機能にて  
TX-8050では聞き取れない局が聞こえる場面もありました。  

【リモコン操作性】  

TX-8050はプリセットメモリ1～40chで、ダイレクト呼び出しの際、  
5～9CHは一発で、それ以外は2桁指定が必要ですが  
リモコンの数字ボタンが小さく操作性に不満がありました。  

本機では、バンク方式とし、バンク内12chは1ボタン選局できるようにしました。  
バンク違いの局をコールするには  
[メニュー] [バンク番号] [ch番号]と3アクション必要ですが  
十字キーの左右でプリセット±する場合は、  
バンクを跨いでchを切り替えます。  

【ワイドFM対応】  
本機ではワイドFMに対応しました。  
（ONKYOレシーバーは後継機種TX-8150でワイドFM対応になりました。）
